# CodeAlpha_ImageGallery

Responsive image gallery built with HTML, CSS and vanilla JavaScript for the CodeAlpha Frontend Development Internship (Task 1).

## Features
- Responsive CSS Grid layout (desktop, tablet, mobile)
- Lightbox view with next / previous buttons
- Keyboard support (← → arrows, Esc) and touch swipe
- Hover zoom, overlay captions and smooth transitions
- **Bonus:** category filters (All, Nature, Travel, Architecture, Animals)

## Run locally
Open `index.html` in any browser. No build step needed.

## Customize
Edit the `images` array at the top of `script.js` to use your own photos and categories.

## Tech
HTML5, CSS3, JavaScript (ES6)
